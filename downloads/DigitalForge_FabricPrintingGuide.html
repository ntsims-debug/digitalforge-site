The workflow (using ChatGPT)

  1. Generate the prompt. In the Dashboard, pick the Surface Patterns — Spoonflower niche, set the generator to ChatGPT/DALL·E, add your style, collection name & vision, then Generate. Prompts are written for seamless repeats.
  2. (Optional) Prompt Player. Load the prompts CSV to copy each prompt one at a time.
  3. Make the tile in ChatGPT. Generate a square image — you'll get 1024×1024. Ask for a "seamless repeating tile," and regenerate if any motif is clipped awkwardly at an edge.
  4. Check your size math. At 150 DPI a 1024px tile is crisp to ~6.8″. Largest repeat ≤6″? skip to step 6. Bigger? do step 5 first.
  5. Export once, then inspect for softness. Any file tagged _UPSCALED (8/12/18/24″ from a 1024px tile) was enlarged and looks softer — the tool warns you which. If those are too soft, enlarge the tile properly first:
    ⚠ Fixing soft (upscaled) tiles — never upscale the raw tile, it breaks the seam
    3×3 (safest): tile 9 copies (3072×3072 for a 1024 tile) → Upscayl at 4× → crop the centre cell (4096×4096, ≈27″ @150). Every edge is upscaled with matching pattern around it, so it stays seamless.
    2×2 (lighter): 4 copies (2048×2048) → 4× → crop a tile from the centre. Then re-drop & re-export — those sizes are now native, not _UPSCALED.
  6. Export fabric-ready tiles. Drop the tile in the 1:1 (Square) box → set Output DPI (150 for Spoonflower, 300 for printers that prefer it) → Export Spoonflower tiles (ZIP). Seamless sRGB PNGs, 2–24″.
  7. Upload to your service. Pick the size, choose the repeat type, and always check the repeat preview for seams before ordering a swatch.

File requirements by service

Your export (seamless sRGB PNG) is the right kind of file for every service below — they all want RGB/sRGB (not CMYK) and a seamless tile. FABRIC printers take your tile directly; POD marketplaces want much bigger files & use their own pattern tools.
